# FFHQ-Makeup samples

Sample pairs from **FFHQ-Makeup** (paper: https://arxiv.org/pdf/2508.03241), downloaded from the
`images/` sample folder of https://huggingface.co/datasets/cyberagent/FFHQ-Makeup (the full
dataset is a 3.8 GB zip: 18k identities x 5 styles, 90k pairs).

Naming: `<id>_bare.jpg` (real FFHQ photo) + `<id>_makeup_01..05.jpg` (synthetic, same identity,
aligned, five styles). 512x512 JPEG.
