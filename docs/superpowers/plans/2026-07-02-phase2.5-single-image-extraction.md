# Phase 2.5: Single-Image Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract a makeup look from a single with-makeup photo by synthesizing the bare face with SSAT makeup removal, then feeding the (photo, pseudo-bare) pair into the existing pair pipeline unchanged.

**Architecture:** A new `removal.py` wraps two vendored inference-only repos — SSAT (AAAI 2022, removal GAN, weights ship in-repo at `quick_start/weights/SSAT.pth`) and face-parsing.PyTorch (BiSeNet, the parser SSAT was trained with). A spike script proves pseudo-pair extraction against ground-truth pairs (FFHQ-Makeup) before `extract.py` gains a single-photo mode. Spec: `docs/superpowers/specs/2026-07-02-single-image-extraction-design.md`.

**Tech Stack:** Python 3.12, PyTorch 2.6 + CUDA (RTX 4060 Ti 8GB), OpenCV, MediaPipe (existing `preprocess.py`), pytest (new dev dep), gdown (weights download).

## Global Constraints

- **All work on branch `phase-2.5-single-image`** — never commit to `master` (user requirement).
- Run everything with the project venv: `.venv/Scripts/python.exe` from repo root.
- `src/` is not installed as a package: repo-root `conftest.py` (Task 1) puts it on `sys.path` for pytest; use `PYTHONPATH=src` for `python -m makeup_transfer.*` commands (bash: `PYTHONPATH=src .venv/Scripts/python.exe -m makeup_transfer.extract ...`).
- **Never compile anything under `third_party/`** (sandbox blocks it; see memory). Both vendored repos are pure-Python inference — clone + download weights only.
- `third_party/*/`, `*.pth`, `looks/*/`, `preprocess_out/` are gitignored — commits touch only `src/`, `tests/`, `docs/`, `conftest.py`, `requirements.txt`.
- Licenses: SSAT is CC BY-NC-SA 4.0, face-parsing.PyTorch is MIT, FFHQ-Makeup is CC BY-NC-SA. Non-commercial R&D use — fine for this local phase; note stays in `references.md`.
- torch 2.6 defaults `torch.load(weights_only=True)`; both checkpoints need explicit `weights_only=False` (we load them ourselves — never call SSAT's `resume()`).
- SSAT's `init_net` hard-asserts CUDA; `removal.py` raises a clear error on CPU-only machines.

## Verified facts (read from the vendored code — do not re-derive)

- SSAT quick_start input contract: RGB float `[-1, 1]`, 256×256, NCHW; parsing = one-hot 18 classes (`semantic_dim=18`, grayscale labels 0–17, face-parsing.PyTorch scheme; label 18 "hat" must be zeroed). Data dict keys: `non_makeup`, `makeup`, `non_makeup_parse`, `makeup_parse` — batched float tensors.
- `MakeupGAN.test_pair(data)` runs the symmetric pass and stores the removal result on `model.z_removal` (1,3,256,256 RGB in [-1,1]). `non_makeup` = bare style **reference**, `makeup` = the photo to strip.
- Checkpoint keys: `enc_c`, `enc_a`, `enc_s`, `enc_trans`, `gen` (load into `enc_content`, `enc_makeup`, `enc_semantic`, `transformer`, `gen`).
- `MakeupGAN(opts)` reads `opts.lr, opts.batch_size, opts.gpu, opts.input_dim, opts.output_dim, opts.semantic_dim`.
- BiSeNet: `BiSeNet(n_classes=19)`, input 512×512 RGB, ImageNet-normalized; output `net(img)[0].argmax(1)` = labels 0–18. Its constructor downloads resnet18 from the PyTorch model zoo on first run (needs network once, then cached).
- Both `SSAT/quick_start/model.py` and `face-parsing.PyTorch/model.py` are named `model.py` and use flat imports (`import networks` / `from resnet import Resnet18`) → load via `importlib` with dependency pre-registration (code in Task 2).
- Existing interfaces: `preprocess.detect_face(image_path) -> FaceData` (`.image` BGR, `.landmarks` (468,2), `.masks` dict with keys `"face"`, `"lips"`, `"left_eye"`, `"right_eye"`, `"left_brow"`, `"right_brow"`, `"mouth"`); `extract.extract_look(with_image, without_image, look_name, *, uv_size, sym, store)` returns `(layer, skin_lab, debug)` with `debug["alpha"]` float HxW; `apply.apply_look(look_name, target_path, uv_size=...) -> (result_bgr, dbg)` with `dbg["target"]`; `storage.LookMeta` is a fixed-field dataclass (`from_dict` drops unknown keys).

```python
"""Phase 2.5: single-image bare-face estimation (makeup removal -> pseudo-pair).

Wraps two vendored, inference-only third-party repos (nothing is compiled):

- ``third_party/SSAT/quick_start`` -- SSAT (AAAI 2022) makeup transfer/removal GAN.
  Weights ship in that repo. Removal is style transfer of "no makeup", so it needs a
  bare *reference* face; any reasonably frontal bare photo works (default below).
- ``third_party/face-parsing.PyTorch`` -- BiSeNet face parsing, the parser SSAT was
  trained with (18 semantic classes; label 18 "hat" is folded into background).

The pseudo-bare output is the *input photograph* with the face crop regenerated at
SSAT's 256x256 training size and pasted back, so the (makeup, pseudo-bare) pair is
pixel-aligned by construction and flows through ``extract.py`` like a real pair.
The 256px bottleneck only degrades the alpha matte, not the layer color (which
comes from the full-res with-makeup photo).

CUDA is required: SSAT's ``init_net`` asserts it.

Run::

    PYTHONPATH=src python -m makeup_transfer.removal data/ffhq_makeup/002386_makeup_03.jpg \
        --out preprocess_out/phase25/pseudo_bare.png
"""

from __future__ import annotations

import argparse
import importlib.util
import sys
from pathlib import Path

import cv2
import numpy as np

from .preprocess import detect_face

_ROOT = Path(__file__).resolve().parents[2]
SSAT_DIR = _ROOT / "third_party" / "SSAT" / "quick_start"
PARSING_DIR = _ROOT / "third_party" / "face-parsing.PyTorch"
SSAT_WEIGHTS = SSAT_DIR / "weights" / "SSAT.pth"
PARSING_WEIGHTS = PARSING_DIR / "res" / "cp" / "79999_iter.pth"
DEFAULT_REFERENCE = _ROOT / "data" / "ffhq_makeup" / "003125_bare.jpg"

SSAT_SIZE = 256      # SSAT training resolution
PARSE_SIZE = 512     # BiSeNet eval resolution
SEMANTIC_DIM = 18    # SSAT one-hot classes (face-parsing labels 0-17; 18 "hat" -> 0)
CROP_EXPAND = 1.6    # square crop half-size = this * max landmark extent / 2


def _load_module(alias: str, path: Path):
    """Import a third-party file under a controlled name (both repos have model.py)."""
    if alias in sys.modules:
        return sys.modules[alias]
    spec = importlib.util.spec_from_file_location(alias, str(path))
    mod = importlib.util.module_from_spec(spec)
    sys.modules[alias] = mod
    spec.loader.exec_module(mod)
    return mod


def _crop_box(landmarks: np.ndarray, shape: tuple) -> tuple[int, int, int, int]:
    """Square face crop around the landmarks, clamped to the frame."""
    h, w = shape[:2]
    lo, hi = landmarks.min(axis=0), landmarks.max(axis=0)
    cx, cy = (lo + hi) / 2.0
    half = float((hi - lo).max()) / 2.0 * CROP_EXPAND
    x0, y0 = int(max(0, cx - half)), int(max(0, cy - half))
    x1, y1 = int(min(w, cx + half)), int(min(h, cy + half))
    return x0, y0, x1, y1


class BareFaceEstimator:
    """SSAT makeup removal behind a small, swappable interface (see design doc)."""

    def __init__(self, default_reference: str | Path = DEFAULT_REFERENCE,
                 device_index: int = 0):
        import torch

        if not torch.cuda.is_available():
            raise RuntimeError("SSAT removal requires CUDA (its init_net asserts it).")
        for pth, hint in ((SSAT_WEIGHTS, "git clone https://github.com/Snowfallingplum/SSAT third_party/SSAT"),
                          (PARSING_WEIGHTS, "see BUILD_PLAN phase 2.5: gdown 154JgKpzCPW82qINcVieuPH3fZ2e0P812")):
            if not pth.exists():
                raise FileNotFoundError(f"Missing weights: {pth}\n  -> {hint}")
        self._torch = torch
        self.device = torch.device(f"cuda:{device_index}")
        self.default_reference = Path(default_reference)
        self._ref_cache: dict[Path, tuple] = {}
        self._load_nets(device_index)

    # --- model loading -----------------------------------------------------
    def _load_nets(self, gpu: int) -> None:
        torch = self._torch
        _load_module("networks", SSAT_DIR / "networks.py")   # ssat model.py does `import networks`
        ssat_model = _load_module("ssat_qs_model", SSAT_DIR / "model.py")
        opts = argparse.Namespace(gpu=gpu, input_dim=3, output_dim=3,
                                  semantic_dim=SEMANTIC_DIM, batch_size=1, lr=2e-4)
        self.gan = ssat_model.MakeupGAN(opts)
        ck = torch.load(SSAT_WEIGHTS, map_location=self.device, weights_only=False)
        self.gan.enc_content.load_state_dict(ck["enc_c"])
        self.gan.enc_makeup.load_state_dict(ck["enc_a"])
        self.gan.enc_semantic.load_state_dict(ck["enc_s"])
        self.gan.transformer.load_state_dict(ck["enc_trans"])
        self.gan.gen.load_state_dict(ck["gen"])
        self.gan.eval()

        _load_module("resnet", PARSING_DIR / "resnet.py")    # bisenet model.py does `from resnet import ...`
        bisenet_mod = _load_module("bisenet_model", PARSING_DIR / "model.py")
        self.bisenet = bisenet_mod.BiSeNet(n_classes=19)     # downloads resnet18 backbone once
        self.bisenet.load_state_dict(
            torch.load(PARSING_WEIGHTS, map_location=self.device, weights_only=False))
        self.bisenet.to(self.device).eval()

    # --- per-image preparation ----------------------------------------------
    def _parse(self, crop_bgr: np.ndarray) -> np.ndarray:
        """BiSeNet labels for a face crop, returned at SSAT_SIZE. Labels 0-17."""
        torch = self._torch
        rgb = cv2.cvtColor(cv2.resize(crop_bgr, (PARSE_SIZE, PARSE_SIZE)), cv2.COLOR_BGR2RGB)
        x = torch.from_numpy(rgb).float().permute(2, 0, 1)[None].to(self.device) / 255.0
        mean = torch.tensor([0.485, 0.456, 0.406], device=self.device).view(1, 3, 1, 1)
        std = torch.tensor([0.229, 0.224, 0.225], device=self.device).view(1, 3, 1, 1)
        with torch.no_grad():
            out = self.bisenet((x - mean) / std)[0]
        labels = out.argmax(1)[0].byte().cpu().numpy()
        labels[labels >= SEMANTIC_DIM] = 0  # "hat" (18) has no SSAT channel
        return cv2.resize(labels, (SSAT_SIZE, SSAT_SIZE), interpolation=cv2.INTER_NEAREST)

    def _tensors(self, image_path: str | Path):
        """photo -> (FaceData, crop box, image tensor, one-hot parse tensor)."""
        torch = self._torch
        face = detect_face(image_path)
        box = _crop_box(face.landmarks, face.image.shape)
        x0, y0, x1, y1 = box
        crop = cv2.resize(face.image[y0:y1, x0:x1], (SSAT_SIZE, SSAT_SIZE),
                          interpolation=cv2.INTER_AREA)
        rgb = cv2.cvtColor(crop, cv2.COLOR_BGR2RGB).astype(np.float32) / 127.5 - 1.0
        img_t = torch.from_numpy(rgb.transpose(2, 0, 1))[None].to(self.device)
        labels = self._parse(crop)
        one_hot = np.zeros((SEMANTIC_DIM, SSAT_SIZE, SSAT_SIZE), dtype=np.float32)
        for i in range(SEMANTIC_DIM):
            one_hot[i][labels == i] = 1.0
        parse_t = torch.from_numpy(one_hot)[None].to(self.device)
        return face, box, img_t, parse_t

    def _reference_tensors(self, reference: Path):
        if reference not in self._ref_cache:
            _, _, img_t, parse_t = self._tensors(reference)
            self._ref_cache[reference] = (img_t, parse_t)
        return self._ref_cache[reference]

    # --- public API ----------------------------------------------------------
    def estimate_bare(self, image_path: str | Path,
                      reference: str | Path | None = None) -> np.ndarray:
        """Synthesize a bare version of a with-makeup photo (full frame, BGR uint8)."""
        torch = self._torch
        ref_img, ref_parse = self._reference_tensors(Path(reference or self.default_reference))
        face, box, img_t, parse_t = self._tensors(image_path)
        data = {"non_makeup": ref_img, "makeup": img_t,
                "non_makeup_parse": ref_parse, "makeup_parse": parse_t}
        with torch.no_grad():
            self.gan.test_pair(data)          # populates gan.z_removal
            removal = self.gan.z_removal[0].cpu().numpy()
        out = ((removal.transpose(1, 2, 0) + 1.0) * 127.5).clip(0, 255).astype(np.uint8)
        out_bgr = cv2.cvtColor(out, cv2.COLOR_RGB2BGR)
        x0, y0, x1, y1 = box
        result = face.image.copy()
        result[y0:y1, x0:x1] = cv2.resize(out_bgr, (x1 - x0, y1 - y0),
                                          interpolation=cv2.INTER_CUBIC)
        return result


_estimator: BareFaceEstimator | None = None


def estimate_bare(image_path: str | Path,
                  reference: str | Path | None = None) -> np.ndarray:
    """Module-level convenience with a lazily created, cached estimator."""
    global _estimator
    if _estimator is None:
        _estimator = BareFaceEstimator()
    return _estimator.estimate_bare(image_path, reference=reference)


def _main() -> None:
    ap = argparse.ArgumentParser(description="Synthesize a bare face from a makeup photo (SSAT removal).")
    ap.add_argument("image", help="with-makeup photo")
    ap.add_argument("--ref", default=None, help="bare reference photo (style source)")
    ap.add_argument("--out", default="preprocess_out/phase25/pseudo_bare.png")
    args = ap.parse_args()
    result = estimate_bare(args.image, reference=args.ref)
    out = Path(args.out)
    out.parent.mkdir(parents=True, exist_ok=True)
    cv2.imwrite(str(out), result)
    print(f"Wrote {out}")


if __name__ == "__main__":
    _main()

"""Phase 2.5 spike: is (makeup, SSAT-pseudo-bare) extraction as good as a real pair?

For each held-out FFHQ-Makeup identity: synthesize the bare face from the makeup
photo alone (reference = a DIFFERENT identity's bare photo, so nothing leaks), run
the existing pair extraction with both the true and the pseudo bare, then compare
alphas and cross-apply both looks to the reference identity.

Gate (design doc): same regions covered / no large false alpha / plausible apply.

Run::

    PYTHONPATH=src python -m makeup_transfer.phase25_spike
"""

from __future__ import annotations

from pathlib import Path

import cv2
import numpy as np

from .apply import apply_look
from .extract import extract_look
from .removal import BareFaceEstimator
from .uv_unwrap import region_masks_uv

DATA = Path("data/ffhq_makeup")
OUT = Path("preprocess_out/phase25")

# (identity, makeup photo, other-identity bare used as removal reference + apply target)
CASES = [
    ("002386", "002386_makeup_03.jpg", "003417_bare.jpg"),
    ("003125", "003125_makeup_02.jpg", "002386_bare.jpg"),
    ("003417", "003417_makeup_05.jpg", "003125_bare.jpg"),
]


def _panel(img: np.ndarray, h: int = 256) -> np.ndarray:
    w = int(round(img.shape[1] * h / img.shape[0]))
    return cv2.resize(img, (w, h), interpolation=cv2.INTER_AREA)


def _gray_panel(a: np.ndarray, h: int = 256) -> np.ndarray:
    g = (np.clip(a, 0, 1) * 255).astype(np.uint8)
    return _panel(cv2.cvtColor(g, cv2.COLOR_GRAY2BGR), h)


def main() -> None:
    OUT.mkdir(parents=True, exist_ok=True)
    est = BareFaceEstimator()
    rows = []

    for ident, makeup_name, ref_name in CASES:
        makeup, true_bare, ref = DATA / makeup_name, DATA / f"{ident}_bare.jpg", DATA / ref_name

        pseudo = est.estimate_bare(makeup, reference=ref)
        pseudo_path = OUT / f"{ident}_pseudo_bare.png"
        cv2.imwrite(str(pseudo_path), pseudo)

        _, _, dbg_pair = extract_look(makeup, true_bare, f"p25-{ident}-pair")
        _, _, dbg_single = extract_look(makeup, pseudo_path, f"p25-{ident}-single")

        a_pair, a_single = dbg_pair["alpha"], dbg_single["alpha"]
        face = region_masks_uv(a_pair.shape[0])["face"] > 0
        mad = float(np.abs(a_pair - a_single)[face].mean())
        false_alpha = float(((a_single > 0.3) & (a_pair < 0.1))[face].mean())
        missed = float(((a_pair > 0.3) & (a_single < 0.1))[face].mean())
        print(f"{ident}: mean|dA|={mad:.4f}  false-alpha={false_alpha:.4f}  missed={missed:.4f}")

        applied_pair, _ = apply_look(f"p25-{ident}-pair", ref)
        applied_single, _ = apply_look(f"p25-{ident}-single", ref)

        row = np.hstack([
            _panel(cv2.imread(str(makeup))), _panel(cv2.imread(str(true_bare))),
            _panel(pseudo), _gray_panel(a_pair), _gray_panel(a_single),
            _panel(applied_pair), _panel(applied_single),
        ])
        cv2.imwrite(str(OUT / f"{ident}_row.png"), row)
        rows.append(row)

    width = max(r.shape[1] for r in rows)
    grid = np.vstack([cv2.copyMakeBorder(r, 0, 8, 0, width - r.shape[1], cv2.BORDER_CONSTANT)
                      for r in rows])
    cv2.imwrite(str(OUT / "spike_grid.png"), grid)
    print(f"Columns: makeup | true bare | PSEUDO bare | alpha(pair) | alpha(single) "
          f"| applied(pair) | applied(single)\nWrote {OUT / 'spike_grid.png'}")


if __name__ == "__main__":
    main()
```
